Politique de confidentialite

Derniere mise a jour : 18 juin 2026

Najib est une application utilisee pour gerer et publier du contenu educatif sur les comptes Meta connectes, notamment une Page Facebook et un compte Instagram professionnel.

Donnees que nous utilisons

L'application peut acceder aux informations autorisees par Meta, comme l'identifiant de la Page Facebook, le nom de la Page, l'identifiant du compte Instagram professionnel, le nom d'utilisateur Instagram et les autorisations necessaires pour publier du contenu.

Utilisation des donnees

Les donnees sont utilisees uniquement pour authentifier le proprietaire, selectionner les comptes connectes et publier les contenus demandes sur Facebook ou Instagram.

Partage des donnees

Nous ne vendons pas les donnees personnelles. Les donnees peuvent etre transmises a Meta uniquement lorsque cela est necessaire pour utiliser les API Facebook et Instagram.

Conservation

Les jetons d'acces et identifiants techniques peuvent etre conserves localement pour permettre la publication. Ils peuvent etre supprimes sur demande ou lorsque l'acces a l'application est retire.
